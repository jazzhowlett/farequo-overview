# FareQuo — Automação de Cotação Aérea

Ferramenta desenvolvida em Python e Streamlit para automatizar o cálculo, precificação, repasse de taxas e formatação visual de cotações de passagens aéreas.

<img width="704" height="240" alt="image" src="https://github.com/user-attachments/assets/15c2af2c-beda-4c66-8caf-638e7b91d86d" />

## O Problema
O processo manual de cálculo de tarifas, margens, repasse de taxas e formatação padronizada levava em média **10 minutos por cotação**, gerando gargalo operacional e risco de erro humano em horários de pico.

## A Solução e Impacto
- **Redução de 98% no tempo operacional:** de ~10 minutos para **10 segundos** por cotação.
- **Precisão financeira:** cálculo automatizado de margens e taxas sem erros manuais.
- **Padronização comercial:** geração instantânea de layout limpo pronto para envio ao cliente.

- **Streamlit** (interface web interativa)
